# Changelog

## v0.1.0

- Added Chrome Manifest V3 extension scaffold.
- Added dynamic request redirects using `chrome.declarativeNetRequest`.
- Added full-tab settings UI opened from the toolbar icon.
- Added per-rule enable and disable controls.
- Added Add Rule and Edit Rule modal dialogs.
- Added Recent Matches diagnostics with request URL and redirect URL columns.
- Added match badge updates and clearable match history.
- Added documentation and troubleshooting screenshots.
